# Grocery dictionary data

`dictionary.generated.ts` is generated by `scripts/groceries/build-dictionary.ts`
(APP-353). Do not edit it by hand: change the script, its rules or
`scripts/groceries/curated.txt`, and run it again. The exact input files are
pinned, with size and SHA-256, in `scripts/groceries/inputs.json`.

Each term carries the sources it came from as bits: Open Facts 1, NEVO 2,
curated 4. `createGroceryDictionary(data, sources)` can leave a source out, so
the NEVO terms can be dropped without a rebuild.

## Sources and licences

### Open Food Facts, Open Beauty Facts, Open Products Facts (ODbL)

Product names, generic names, brands and categories of products sold in the
Netherlands or Belgium, and the Open Food Facts category taxonomy. No barcodes,
nutrition or images are used.

This list contains information from Open Food Facts, Open Beauty Facts and
Open Products Facts (https://world.openfoodfacts.org,
https://world.openbeautyfacts.org, https://world.openproductsfacts.org), made
available under the Open Database License (ODbL) 1.0:
https://opendatacommons.org/licenses/odbl/1-0/. The terms in
`dictionary.generated.ts` are a derived database and are likewise available
under the ODbL 1.0. Gather's code is not covered by this licence.

### NEVO online 2025/9.0 (RIVM)

Food names, synonyms and food groups only. Based on data from NEVO online
version 2025/9.0, RIVM, Bilthoven.

NEVO's conditions of use apply: the data is used unchanged with its source and
version cited, Gather's own additions (the aisle each food group maps to) are
marked as such in the build script, and NEVO data may not be charged for. As
ADR-0006 in the workouts repository records, the NEVO terms must be removed
(build without them, or pass `sources` without bit 2) or relicensed before
users are charged for a plan that includes this list.
