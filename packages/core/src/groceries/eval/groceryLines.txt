# Grocery eval set (APP-353)
#
# Real grocery-list lines as people type them on a phone: Dutch and English,
# brands and store brands, plurals, typos, compounds and amounts. Written by
# hand before the dictionary existed, and never generated from it: the score
# is only worth something while this file stays independent of the data it
# measures. Add lines when a real list shows a miss; never edit a label to
# make a score go up.
#
# Columns, separated by `|` and trimmed:
#   line      what the person typed
#   aisle     the expected aisle id (designs/groceries/README.md)
#   quantity  the expected amount, `.` as decimal point; empty when none
#   unit      the expected unit id (`@gather/core/groceries` UNITS); empty when none
#   name      the expected name once amount and unit are taken off; empty
#             means the whole line
#
# Aisle conventions for the cases a Dutch supermarket splits differently:
#   eggs, butter, margarine, cream, plant drinks, chilled desserts, chocolate
#     milk -> dairy
#   sliced meats, cheese, hummus and chilled spreads -> cheese_deli
#   fresh meat, fish, smoked sausage, bacon, meat substitutes, tofu -> meat_fish
#   rice, pasta, noodles, wraps, pasta sauce, pesto, Asian and Mexican
#     ingredients -> pasta_world
#   tins, jars, soup, oil, vinegar, spices, condiments, baking staples (flour,
#     sugar, yeast) -> tins_sauces
#   cereal, spreads, honey, jam, crackers, rusks, coffee, tea -> breakfast
#   biscuits, sweets, chocolate, crisps, nuts, dried fruit -> snacks
#   anything sold frozen -> frozen
#   water, soft drinks, juice, beer, wine, spirits, squash -> drinks
#   toiletries, medicine, baby food, nappies -> care_baby
#   cleaning, paper goods, bags and foil, batteries, pet food -> household
#   not something a supermarket sells -> other
