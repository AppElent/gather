# Tasting Modules on the phone

The design of record for issue #199's native screens. Published as a Claude
Design canvas at
<https://claude.ai/code/artifact/1f030809-ebfe-4fa3-82c2-9a1c14c1a44d>; the
artboards and `canvas.json` beside this file are that canvas's source, kept
here so the design outlives the URL.

`canvas.json` carries the annotations, which are where the reasoning is —
what each capture direction claimed, why the mix won, and the one thing left
open (whether the subject step offers a photo before the composer; it does
not — the photo lives on the subject page).

The published single-file bundle is **not** committed: it is 2.4 MB of
inlined runtime, it is regenerated on every publish, and the artifact URL
already serves it. It is ignored below.
