# Money is shared and calculation-first

Money tools are shared within a Group, but are calculation-first rather than a
household ledger. Gather begins with mortgage payment, repayment, and
fixed-rate-expiry scenarios plus one-off Payment splits; results are disposable
unless explicitly saved as immutable Group scenarios, which Members duplicate
to change. Mortgage tools are Netherlands-specific where local rules matter,
support annuity and linear structures, and display only Member-entered rate
assumptions with an estimate-not-advice notice. These calculators live as
dedicated screens in one Finances / Money tools Module; neither the split tool
nor a scenario creates a running debt, settlement history, bank connection, or
CSV import. Mortgage scenarios may be existing or hypothetical, model one-off
or recurring extra repayments, and include an optional Member-entered
early-repayment charge; a Payment split may collect several Members' payments
for one event before calculating contributions. The agreed next tools are
Savings goal, Netherlands-specific Home-buying costs, a manually entered Net
worth snapshot, and Subscription comparison; each follows the same transparent
calculation and optional Saved scenario pattern. The existing Bills &
subscriptions Module folds into Finances as Recurring costs. Net worth consumes
Portfolio's calculated value while its other current values are manual; Savings
goal progress is entered manually; Home-buying costs calculate cash needed and
an estimated monthly payment without assessing affordability. Subscription
comparison compares manually entered plans, including a hypothetical price rise,
without managing cancellation or renewal. Net worth history consists only of
explicitly saved dated snapshots. On mobile, the Finances index leads with the
decision tools before its Portfolio and Net worth overviews.
