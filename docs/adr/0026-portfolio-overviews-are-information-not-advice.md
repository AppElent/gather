# Portfolio overviews are information, not advice

The Portfolio overview is Group-owned and tracks listed stocks and ETFs, using
delayed or end-of-day prices with an explicit timestamp. It supports both
dated current-position entry and transaction history, with later transactions
building on that opening position. It records buys, sales, dividends, and fees;
shows current value, invested amount, unrealized performance, and informational
realized-gain and dividend totals; preserves each holding's trading currency;
and translates aggregate value to the Group home currency with an exchange-rate
timestamp. It uses average cost for those informational figures, displays the
last known quote or exchange rate as stale when refresh fails, and leaves stock
splits, mergers, and ETF changes to a Manual adjustment rather than an automatic
provider action. It has no historical portfolio-value chart. It excludes broker
connections, live prices, tax reporting, asset classes beyond stocks and ETFs,
price predictions, and buy/sell recommendations; it informs a household's
conversations without acting as an investment adviser.
