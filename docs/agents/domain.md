# Domain docs

Single context: the glossary is [`GLOSSARY.md`](../../GLOSSARY.md) at the repo root,
and decisions are in [`docs/adr/`](../README.md#decisions). Use the glossary's terms in
issue titles, hypotheses and test names; name any conflict with an accepted ADR
before reopening it. Two ADR numbers are shared by two files each — see the
[ADR index](../README.md#decisions).
