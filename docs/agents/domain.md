# Domain docs

Single context: the glossary is [`CONTEXT.md`](../../CONTEXT.md) at the repo root,
and decisions are in [`docs/adr/`](../adr/README.md). Use the glossary's terms in
issue titles, hypotheses and test names; name any conflict with an accepted ADR
before reopening it. Two ADR numbers are shared by two files each — see the
[ADR index](../adr/README.md).
