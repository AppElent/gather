# Issue tracker: Linear

Work lives in Linear: workspace `appelent`, team AppElent (key `APP`), project
Gather, label `app:gather`. Requests and PRDs are Linear issues, not GitHub
issues; use the Linear tools to create, read, comment on, and label them. An
older GitHub issue synced to Linear is a mirror: change its status in Linear,
because closing it on GitHub cancels the Linear issue.

**PRs as a request surface: no.** External PRs are not triaged as feature requests.

When a skill says "publish to the issue tracker", file a Linear issue with the
`Agent-ready issue` template. When it says "fetch the relevant ticket", read the
Linear issue and its comments. Labels and statuses: [triage labels](triage-labels.md)
and the Factory workflow in [AGENTS.md](../../AGENTS.md#factory-workflow).
